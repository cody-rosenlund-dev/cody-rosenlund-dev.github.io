# Cody Rosenlund's portfolio

A dependency-free, accessible static portfolio for GitHub Pages.

## Local preview

Run `python3 -m http.server 8765 --bind 127.0.0.1` in this directory, then open http://127.0.0.1:8765.

## Publishing

In GitHub Settings > Pages, choose Deploy from a branch, main, / (root).
The site is intended for https://cody-rosenlund-dev.github.io.

## Editing

- `index.html`: introduction, case studies, about, and contact.
- `style.css`: responsive layout and typography.
- `resume.html`: general resume with a print/save-as-PDF option.
- `.nojekyll`: serve the files directly without Jekyll processing.

Project descriptions summarize existing career material. Review wording before publishing. The site does not include company source code, internal screenshots, private service addresses, or the Cortex vault. Resume phone number omitted from this public-facing draft.
